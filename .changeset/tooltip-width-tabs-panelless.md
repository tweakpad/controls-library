Tooltip: `wrap` and `max-width` set how a tooltip fits its text. By default a tooltip is as wide as its text on one line, up to the available width; `max-width` limits it to a CSS length, `wrap` breaks the text onto more lines at that width, and without `wrap` a longer line is cropped. Long text no longer overflows the tooltip. Tabs without panels drop the panels box, so they are only as tall as their tab list.
