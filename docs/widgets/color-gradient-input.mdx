## Usage

The value is a list of stops, each `{ position, color, midpoint? }`: `position` runs from 0 to 1 along the gradient, `color` is any CSS color notation, and `midpoint` is where, within the span to the next stop, the two colors mix half and half (0.5 when left out). `value` always reads back sorted by position. The stops describe no particular renderer: draw them with CSS, a canvas or a shader.

Press the track to add a stop in the gradient's own color at that point; it is selected and follows the pointer until release. Drag a stop to move it, past its neighbors if you like; it keeps its color, its midpoint and its selection. Drag a diamond above the track to move a midpoint. Escape during a drag puts everything back. The Button at the end removes the selected stop; `min-stops` (2 by default) is the fewest the gradient keeps, and `removable="false"` hides the Button.

`default-value` takes the stops as JSON; `value` and `defaultValue` take them as an array. Changes arrive as `tp-value-change` proposals while you drag and as one `tp-value-commit` when the gesture settles. In a form, the stops submit as JSON under `name`.

### Composing a stop editor

The element edits the stops only and opens nothing. A stop's color, its location as a number, the gradient's angle and its shape are separate controls you compose around it: read the selected stop from `value[selected]`, and write a change back with `setStop(index, changes)`, which keeps a moved stop selected. `setValue(stops)` and `setSelected(index)` propose whole changes the same way, in either controlled or uncontrolled use.

  <tp-input variant="inline" label="Rotation" type="number" unit="deg" min="0" max="360" default-value="90"></tp-input>

  script={`const root = document.querySelector('#gradient-compose');
const gradient = root.querySelector('tp-color-gradient-input');
const color = root.querySelector('tp-color-input');
const location = root.querySelector('tp-input[label="Location"]');
// The rows show the selected stop; editing a row changes that stop.
const show = () => {
  const stop = gradient.value[gradient.selected];
  color.setValue(stop?.color ?? '');
  location.setValue(stop ? String(Math.round(stop.position * 100)) : '');
};
const edited = (event) => event.detail.reason !== 'programmatic';
gradient.addEventListener('tp-value-commit', show);
gradient.addEventListener('tp-selection-change', () => queueMicrotask(show));
color.addEventListener('tp-value-change', (event) => {
  if (edited(event)) gradient.setStop(gradient.selected, { color: event.detail.value });
});
location.addEventListener('tp-value-change', (event) => {
  const position = Number(event.detail.value) / 100;
  if (edited(event) && Number.isFinite(position))
    gradient.setStop(gradient.selected, { position: Math.min(1, Math.max(0, position)) });
});
customElements.whenDefined('tp-color-gradient-input').then(() => gradient.updateComplete).then(show);`}
/>

A diamond above the track marks each midpoint. Moving it toward a stop keeps the other stop's color longer; it stays between 5 % and 95 % of its span, and stops at one position leave no midpoint to move.

### Interpolation and sampling

`interpolation` is the color space neighboring stops mix in, `oklab` (the default) or `srgb`; set it to the space your renderer mixes in, so the track shows what it will draw. `sample(t)` returns the color at any point, and `sampleColorGradient(stops, t, interpolation)` does the same without the element, for example to bake a ramp texture.

<Code
  label="Baking a ramp for a canvas"

for (let x = 0; x < canvas.width; x++) {
  const color = sampleColorGradient(gradient.value, x / (canvas.width - 1), 'oklab');
  ramp.fillStyle = serializeColor(color, 'rgb');
  ramp.fillRect(x, 0, 1, canvas.height);
}`}

### Sizes and states

`size="sm"` fits the editor into a compact panel. `disabled` and `readonly` keep the stops visible and stop every edit; a read-only editor still lets you focus and read each handle.

### Keyboard

Every stop and midpoint is a slider. The arrows move it by `step` (0.01), Shift, Control or Meta with an arrow and Page Up or Page Down by ten steps, Alt with an arrow by a tenth of a step, and Home and End to the ends; the horizontal arrows follow the writing direction. Delete or Backspace removes the focused stop. Focusing a stop selects it, and keyboard changes commit at once.

### Accessibility

The root is a group named by `label` (default "Gradient"). Stops are sliders named `Fill: Stop 2 of 4` whose value text is the position and the color; midpoints are sliders named `Fill: Midpoint between stops 1 and 2`. Focus follows the visual order: each stop, then the midpoint after it, then the remove Button. `strings` replaces every name.
