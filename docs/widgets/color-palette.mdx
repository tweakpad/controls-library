## Usage

The value is the color text the collection gives for the chosen swatch, and it submits with a form under `name`. Colors sit next to each other without gaps or lines between them, so small differences in grading stay visible. The list takes focus as one control: the arrow keys move through the grid, letters jump to a color by name, and Enter or Space picks. The list is virtualized, so a collection of several hundred colors stays fast. The palette always offers its built-in default collection, and `collections` loads more.

A pick of a different color proposes a cancelable `tp-value-change` whose metadata names the swatch and the collection, followed by `tp-value-commit`. Supply `value` for a controlled palette or `defaultValue` for an uncontrolled one; the mode stays fixed for the element's lifetime. The same rule applies to the mode, collection, layout, palette style, grouping, sort, sort direction, size and favorites lanes.

The status bar under the list shows the chosen color in `format` (`hex` by default, or `rgb`, `hsl`, `hwb`, `hsv`, `lab`, `oklab`, `oklch` or `cmyk`) with its name, or the chosen palette's name and size. Its copy button copies that color, or every color of the palette, and its heart adds the choice to the favorites or removes it. With nothing chosen, the bar names the active collection and how many colors or palettes it lists, or counts the favorites.

<Preview
  title="Picks"
  code={`<tp-stack gap="3" align="center">
  <tp-color-palette
    id="color-palette-picks"
    label="Header fill"
    default-value="#1e6dd8"
  ></tp-color-palette>
  <output
    id="color-palette-picks-output"

  script={`const palette = document.querySelector('#color-palette-picks');

palette.addEventListener('tp-value-commit', (event) => {
  const swatch = event.detail.metadata.swatch;
  output.textContent = \`Header fill: \${swatch.name ?? swatch.value}\`;
});`}
/>

### Collections

A collection is a JSON document: its colors as color texts or as records with a name and a group, optional groups in display order, optional preset palettes of two to twelve colors with their shares, an optional description, and who made it. The default and a reduced collection ship with `@tweakpad/ui/color-palette`; every other collection is its own import from `@tweakpad/ui/color-palette/collections/<id>`, so an application bundles only the collections it uses. Once a collection is loaded, Color libraries in the view options lists the default collection and then the loaded ones; the palette opens on the first loaded collection. When the active collection names its source and nothing is chosen, an info icon at the start of the status bar shows the source and its license in a Tooltip on hover or focus; a collection with a description shows a Preview Card instead, with the source as a link, the description and the license.

<Code

  "colors": [

    { "value": "#2a6f97", "name": "Tide", "group": "blues" },

/>

A document fetched at run time goes through `parseColorCollection`, which drops malformed entries and lists them as issues; colors that do not parse are reported as diagnostics when the palette shows the collection.

<Code
  label="Loading a collection"
  language="typescript"
  code={`import { parseColorCollection } from '@tweakpad/ui/color-palette';

const response = await fetch('/collections/harbor.json');
const { collection, issues } = parseColorCollection(await response.json());
palette.collections = [collection];`}
/>

### Grouping and sorting

The grid groups colors as the collection does by default. `grouping="hue"` regroups them into hue families with the neutrals last, and `grouping="none"` lists one flat grid. `sort` orders each group by lightness, hue or chroma instead of the collection's order, which turns a scattered collection into readable gradings. Group by in the view options beside the mode tabs offers three choices: Auto shows the hue families ordered by lightness, Collection the collection's own groups and order, and None one flat grid in the collection's order.

<Preview
  title="Hue families by lightness"
  code={`<tp-color-palette
  id="color-palette-sorted"
  label="Named colors"
  default-grouping="hue"
  default-sort="lightness"
></tp-color-palette>`}
  script={`import { cssNamedColors } from '@tweakpad/ui/color-palette/collections/css-named';

document.querySelector('#color-palette-sorted').collections = [cssNamedColors];`}
/>

### List

`layout="list"` shows the grid as one row per color: its color, one cell tall and three cells wide, then its name, or its HSL values when the color has no name. It is also under Display in the view options. The rows keep the height of the grid's cells and the palette keeps its width.

<Preview
  title="List"
  code={`<tp-color-palette label="Ink" default-layout="list" default-value="#1e6dd8"></tp-color-palette>`}
/>

### Palettes

`mode="palettes"` lists the collection's palettes, one row each. A palette holds two to twelve colors, and its weights set each color's share of the row; without weights the colors share it equally. A collection without palettes shows an empty state instead. Pressing a color of a palette picks that color and marks the whole palette as chosen.

`palette-style="gradient"` blends each palette into one gradient whose colors stay pickable, each at the middle of its share; the default `stops` shows the colors side by side. Display in the view options switches between Hard stops and Gradient.

<Preview
  title="Palettes as gradients"
  code={`<tp-color-palette
  label="Theme"
  default-mode="palettes"
  default-palette-style="gradient"
  default-value="#e64a7c"
></tp-color-palette>`}
/>

### Favorites

`mode="favorites"` lists the colors, palettes and gradients you bookmarked, in three sections, each palette and gradient under its name. Double-click a color to add it, or a color of a palette to add the whole palette; a palette shown as a gradient is added as a gradient. A heart appears in the color or across the palette for two seconds to confirm it. In the favorites, double-click a favorite to remove it; Delete or Backspace removes the highlighted favorite, and so does Remove from favorites in its context menu. Each change proposes a cancelable `tp-favorites-change` whose metadata names the `action` and the `favorite`.

Favorites are kept in local storage under `storage-key` by default. To keep them in your own state instead, set `persistence="none"`, pass them as `favorites` and write the proposed list back.

<Preview
  title="Favorites"
  code={`<tp-color-palette id="color-palette-favorites" label="Fill" persistence="none"></tp-color-palette>`}
  script={`const palette = document.querySelector('#color-palette-favorites');
let favorites = [
  { kind: 'color', value: '#e64a7c', name: 'Rose 500' },
  { kind: 'gradient', name: 'Lagoon', colors: ['#143e79', '#00a392', '#b3e9f6'] },
];
palette.favorites = favorites;
palette.mode = 'favorites';
palette.addEventListener('tp-favorites-change', (event) => {
  favorites = event.detail.value;
  palette.favorites = favorites;
});`}
/>

### Size and density

`size` sets the cell size, Small, Medium or Large (24, 32 and 42 px, or 16, 24 and 32 px in a compact region), and is also under Size in the view options; the grid and the list share it. The palette keeps its size: smaller or larger cells reflow inside it, more or fewer to a row. `columns` sets how many medium cells wide the palette is. Only the density of the region resizes the palette: in a `density="compact"` region it shrinks with the controls around them.

### In a popover

The palette is made for floating panels: put it in a Popover next to the control it fills. Hide the toolbar with `toolbar="false"` when one presentation is enough.

### Keyboard

Focusing the list with the keyboard highlights the chosen color, or the first one.

| Key                    | Action                                                                                |
| ---------------------- | ------------------------------------------------------------------------------------- |
| Down, Up               | Next or previous row, keeping the column; the first color when nothing is highlighted |
| Left, Right            | Previous or next color in the row, following the writing direction                    |
| Home, End              | First or last color                                                                   |
| Letters                | The next color whose name starts with the typed letters                               |
| Enter, Space           | Pick the highlighted color                                                            |
| Delete, Backspace      | Remove the highlighted favorite                                                       |
| Shift+F10, Menu        | Open the context menu of the highlighted favorite                                     |
| Arrows on the tabs     | Move between colors and palettes                                                      |
| Tab                    | Reach the tabs, the view options, the list, the copy button and the source info       |

Pressing a color picks it, and double-clicking it adds it to the favorites, or removes it in the favorites. Only the chosen color is marked, with a white and a black line along its edge; in a palette the line runs around the whole palette.
