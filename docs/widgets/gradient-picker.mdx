## Usage

The default `linear` variant edits stops along a track; the `field` variant edits color anchors placed anywhere on a field (see Field gradients below). In the linear variant the value is a list of stops, each `{ position, color, midpoint? }`: `position` runs from 0 to 1 along the gradient, `color` is any CSS color notation, and `midpoint` is where, within the span to the next stop, the two colors mix half and half (0.5 when left out). `value` always reads back sorted by position. The stops describe no particular renderer: draw them with CSS, a canvas or a shader.

Press the track to add a stop in the gradient's own color at that point; it is selected and follows the pointer until release. Drag a stop to move it, past its neighbors if you like; it keeps its color, its midpoint and its selection. Drag a diamond above the track to move a midpoint. Escape during a drag puts everything back. The Button at the end removes the selected stop; `min-stops` (2 by default) is the fewest the gradient keeps, and `removable="false"` hides the Button.

`default-value` takes the stops as JSON; `value` and `defaultValue` take them as an array. Changes arrive as `tp-value-change` proposals while you drag and as one `tp-value-commit` when the gesture settles. In a form, the stops submit as JSON under `name`.

### Composing a stop editor

The element edits the stops only and opens nothing. A stop's color, its location as a number, the gradient's angle and its shape are separate controls you compose around it: read the selected stop from `value[selected]`, and write a change back with `setStop(index, changes)`, which keeps a moved stop selected. `setValue(stops)` and `setSelected(index)` propose whole changes the same way, in either controlled or uncontrolled use.

<Preview
  title="Stop controls"
  align="stretch"
  code={`<div id="gradient-compose" style="display:grid;gap:var(--tp-space-2);max-inline-size:24rem;margin-inline:auto">
  <tp-gradient-picker label="Fill" default-selected="0" default-value='[{"position":0,"color":"#f97316"},{"position":0.6,"color":"#db2777"},{"position":1,"color":"#7c3aed"}]'></tp-gradient-picker>
  <tp-color-input variant="inline" label="Stop color"></tp-color-input>
  <tp-input variant="inline" label="Location" type="number" unit="%" min="0" max="100"></tp-input>
  <tp-input variant="inline" label="Rotation" type="number" unit="deg" min="0" max="360" default-value="90"></tp-input>
</div>`}
  script={`const root = document.querySelector('#gradient-compose');
const gradient = root.querySelector('tp-gradient-picker');
const color = root.querySelector('tp-color-input');
const location = root.querySelector('tp-input[label="Location"]');
// The rows show the selected stop; editing a row changes that stop.
const show = () => {
  const stop = gradient.value[gradient.selected];
  color.setValue(stop?.color ?? '');
  location.setValue(stop ? String(Math.round(stop.position * 100)) : '');
};
const edited = (event) => event.detail.reason !== 'programmatic';
gradient.addEventListener('tp-value-commit', show);
gradient.addEventListener('tp-selection-change', () => queueMicrotask(show));
color.addEventListener('tp-value-change', (event) => {
  if (edited(event)) gradient.setStop(gradient.selected, { color: event.detail.value });
});
location.addEventListener('tp-value-change', (event) => {
  const position = Number(event.detail.value) / 100;
  if (edited(event) && Number.isFinite(position))
    gradient.setStop(gradient.selected, { position: Math.min(1, Math.max(0, position)) });
});
customElements.whenDefined('tp-gradient-picker').then(() => gradient.updateComplete).then(show);`}
/>

/>

A diamond above the track marks each midpoint. Moving it toward a stop keeps the other stop's color longer; it stays between 5 % and 95 % of its span, and stops at one position leave no midpoint to move.

### Interpolation and sampling

`interpolation` is the color space neighboring stops mix in, `oklab` (the default) or `srgb`; set it to the space your renderer mixes in, so the track shows what it will draw. `sample(t)` returns the color at any point, and `sampleLinearGradient(stops, t, interpolation)` does the same without the element, for example to bake a ramp texture.

<Code
  label="Baking a ramp for a canvas"
  language="typescript"
  code={`import { sampleLinearGradient, serializeColor } from '@tweakpad/ui/widgets';

const ramp = canvas.getContext('2d')!;
for (let x = 0; x < canvas.width; x++) {
const color = sampleLinearGradient(gradient.value, x / (canvas.width - 1), 'oklab');
ramp.fillStyle = serializeColor(color, 'rgb');
ramp.fillRect(x, 0, 1, canvas.height);
}`}
/>

### Sizes and states

`size="sm"` fits the editor into a compact panel. `disabled` and `readonly` keep the stops visible and stop every edit; a read-only editor still lets you focus and read each handle.

### Field gradients

<Preview
  title="Field"
  align="stretch"
  code={`<tp-gradient-picker variant="field" label="Sky" default-selected="0" default-value='[{"x":0.2,"y":0.3,"color":"#f97316"},{"x":0.55,"y":0.65,"color":"#7c3aed"},{"x":0.85,"y":0.25,"color":"#0ea5e9"}]' style="max-inline-size:28rem;margin-inline:auto"></tp-gradient-picker>`}
/>

`variant="field"` places color anchors anywhere on a field, each `{ x, y, color }` with `x` and `y` from 0 to 1 from the top start; every point of the field blends all anchors, each weighted by how close it is. Drag an anchor to move it, double press the field's empty space to add one in the field's own color there, and remove the selected one with the Button or Delete. A field keeps 1 to 8 anchors unless `min-stops` and `max-stops` say otherwise, and `value` keeps the anchors in their given order.

`falloff` sets how an anchor's weight drops with distance: `inverse-distance` (the default) divides by the distance raised to `power`, and `gaussian` is a bell that narrows as `power` grows (0.4 to 6, 2.2 by default). `warp-amplitude` (0 to 0.6) and `warp-frequency` (0.3 to 4) bend the borders between colors into waves. `projection="equirectangular"` (the default) reads `x` as longitude and `y` as latitude, so the field wraps at its left and right edges as an environment map does; `projection="plane"` measures straight across a flat field. Like the stops' colors, these are settings you bind to your own controls.

const picker = root.querySelector('tp-gradient-picker');
root.querySelector('tp-select').addEventListener('tp-value-change', (event) => {
  picker.falloff = event.detail.value;
});
const [power, warp] = root.querySelectorAll('tp-slider');
power.addEventListener('tp-value-change', (event) => (picker.power = event.detail.value));
warp.addEventListener('tp-value-change', (event) => (picker.warpAmplitude = event.detail.value));`}
/>

To draw the field outside the element, `sampleFieldGradient(anchors, x, y, options)` returns the color at one point, and `renderFieldGradient(anchors, width, height, options)` fills RGBA pixels, row by row from the top, ready for `ImageData` or a texture upload. The options are the element's settings: `falloff`, `power`, `warpAmplitude`, `warpFrequency`, `projection` and `interpolation`.

<Code
  label="Baking a field texture"
  language="typescript"
  code={`import { renderFieldGradient } from '@tweakpad/ui/widgets';

const pixels = renderFieldGradient(picker.value, 1024, 512, {
falloff: picker.falloff,
power: picker.power,
warpAmplitude: picker.warpAmplitude,
warpFrequency: picker.warpFrequency,
projection: picker.projection,
interpolation: picker.interpolation,
});
context.putImageData(new ImageData(pixels, 1024, 512), 0, 0);`}
/>

### Keyboard

Every stop and midpoint is a slider. The arrows move it by `step` (0.01), Shift, Control or Meta with an arrow and Page Up or Page Down by ten steps, Alt with an arrow by a tenth of a step, and Home and End to the ends; the horizontal arrows follow the writing direction. Delete or Backspace removes the focused stop. A field anchor has a horizontal and a vertical slider: on either, the horizontal arrows move it across and the vertical arrows up and down, without mirroring, while Page Up, Page Down, Home and End act on the focused one. Focusing a stop selects it, and keyboard changes commit at once.

### Accessibility

The root is a group named by `label` (default "Gradient"). Stops are sliders named `Fill: Stop 2 of 4` whose value text is the position and the color; midpoints are sliders named `Fill: Midpoint between stops 1 and 2`; field anchors are pairs of sliders named `Sky: Anchor 1 of 3 horizontal` and `… vertical`, and the field itself is hidden from assistive technology. Focus follows the visual order: each stop, then the midpoint after it, then the remove Button. `strings` replaces every name.
