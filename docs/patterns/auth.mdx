## Sign in

Provider sign-in comes first, then email and password. The email field accepts what password managers fill, the password can be shown to check it, and a failed attempt shows one message that never says which of the two was wrong. The password is selected for the next try, so typing replaces it.

## Create account

One name field, the email address and a new password whose rule is stated before it is typed; browsers can suggest a strong password, and there is no second password to retype. Accepting the terms is required. The email is confirmed with a code next, and the screen after submitting is the same whether or not the address already has an account.

### Set a new password

The link from the email opens this screen. The account's email is shown read-only so password managers save the new password for the right account. An expired or used link offers a new one.

      <tp-input type="email" name="username" autocomplete="username" default-value="jordan@tweakpad.com" readonly></tp-input>
    </tp-field>

      <tp-input type="password" name="password" autocomplete="new-password" minlength="12" enterkeyhint="done" revealable required></tp-input>
    </tp-field>

  </tp-form>

<tp-card id="auth-reset-done" hidden>
  <h2 slot="header">Password changed</h2>

  script={`const reset = document.querySelector('#auth-reset');
const expired = document.querySelector('#auth-reset-expired');
const submit = document.querySelector('#auth-reset-submit');
let attempts = 0;
document.querySelector('#auth-reset-form').onFormSubmit = async () => {
  expired.hidden = true;
  Object.assign(submit, { loadingPosition: 'leading', disabled: true, focusableWhenDisabled: true });
  // Stands in for your request; the first attempt finds the link expired.

};`}

## Verification code
